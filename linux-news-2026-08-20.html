XWayland 26.1 RC1 发布：自 2024 年 XWayland 24.1 以来首个特性版本
显示
Red Hat 的 Olivier Fourdan 今日宣布 XWayland 26.1 首个候选版本。这是自 2024 年 XWayland 24.1 以来首个带新特性的标记发布，累积了两年的改动（数百项）。关键更新：移除 EGLStream 支持（如今 NVIDIA Linux 驱动栈已无需它即可良好工作）；rootful 模式新增 剪贴板/主选区桥接（-clipboard 启用，可在 rootful XWayland 与 Wayland 桌面间复制粘贴）；通过 X Input 2 实现多席位（multi-seat）兼容；支持 Wayland wl_fixes 协议（destroy_global / ack_global_remove）；RandR 模拟优先使用原生模式直至物理分辨率、且模拟模式现考虑旋转；rootful 全屏默认直接使用输出真实分辨率（而非放大 640×480）；新增 xdg-system-bell 协议支持。目前尚无新的 X.Org Server 整体特性发布计划，仅 XWayland 独立推进。
关注理由：XWayland 是 Linux 纯 Wayland 桌面上运行遗留 X11 应用的关键桥梁。时隔两年迎来重大特性版本，移除 EGLStream 标志着 NVIDIA 已彻底转向 GBM 路径、XWayland 对 NVIDIA 用户的体验不再依赖私有扩展；rootful 剪贴板桥接、multi-seat、改进 RandR 模拟则直接改善 Steam/Proton 游戏与多席位场景下的显示与交互完整性，对 Linux 桌面显示栈是实质性进步。

Linux 7.3 调度器改进：提升游戏性能、降低调度延迟、修复 Intel 混合 CPU 调度
计算
Linux 7.3 合并窗口已合入一批令人振奋的调度器更新。其一是 Intel 工程师 Peter Zijlstra 的「flatten the pick」系列：改进 cgroup 调度（新增 cgroup_mode 的 up/max/concur/tasks 多种权重分配方式，默认 concur）、并将 cgroup 调度改为单一运行队列（single runqueue）。该系列在 Intel Sandy Bridge + AMD Radeon RX 580（Polaris）上测试显示出可观的游戏性能提升。其二是降低短切片（short-slice）任务的调度延迟，Vincent Guittot 在 cyclictest 中展示了显著改善。此外修复了非对称容量 CPU（即 Intel 混合架构）的 cluster 调度，并为 NOHZ 负载均衡优先选择完全空闲的核心。
关注理由：「flatten the pick」明确以游戏负载为优化目标、且在搭配 AMD 独显的老平台上实测出增益，是 Linux 游戏（Steam/Proton）体验的底层红利；短切片延迟下降利好实时/交互场景，混合 CPU cluster 调度修复则让 Intel Core Ultra 等大小核机型在 Linux 上的调度更合理。三者共同构成 7.3 内核在「计算/图形负载调度」上的重要进步。
3
AMD 低功耗核心类型 + Intel/AMD 统一核心类型处理合入 Linux 7.3
计算
6 月由 Phoronix 率先报道的 AMD「低功耗（low power）CPU 核心类型」补丁现已合入 Linux 7.3。x86/cpu pull 新增 AMD_CPU_TYPE_LOW_POWER，用于识别这款即将到来的低功耗核心（此前被误判为 unknown，推测服务于 Zen 6 客户端平台），与既有的 performance / efficiency 核心形成互补。与此同时，Linux 7.3 统一了 Intel/AMD 的 CPU 核心类型处理——将厂商专属核心类型映射为通用核心类型（这一统一需求源自 Sashiko AI bot 指出各厂商核心类型编号差异造成的混乱）。同期合入的 x86/core 改动还包括：AMD Athlon XP 时代（支持 SSE 但不支持 SSE2）的写内存屏障 WMB SFENCE 优化、惠及老 Intel CPU 的 KCFI 优化，以及将 32 位 MSR 接口迁移至 64 位接口以简化代码（32 位接口预计于 7.4 删除）。
关注理由：AMD 低功耗核心类型正式落地 + 厂商核心类型统一处理，是 Zen 6 客户端平台调度与电源管理的基础铺垫，也让内核不再为不同厂商的核心类型各自维护割裂逻辑。对关注 AMD 下一代客户端 CPU 在 Linux 上调度/能效表现的开发者，这是 7.3 周期里值得跟踪的底层改动。
