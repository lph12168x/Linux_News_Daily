Linux 7.2 正式发布：缓存感知调度、AMDGPU HDMI 2.1 FRL、Intel Arc B390 图形提升
显示 内核 计算
Linus Torvalds 于 8 月 16 日发布 Linux 7.2 稳定版，将进入 Ubuntu 26.10 等发行版。本周期因 AI/LLM 带来大量补丁与报告潮而格外繁忙，但最终如期发布。图形/显示/计算相关特性包括：缓存感知调度（Cache Aware Scheduling） 提升拥有多末级缓存（LLC）域系统的性能；AMDGPU 初步 HDMI 2.1 FRL 支持（默认关闭，VRR/ALLM 仍未进）；Intel Arc B390（Panther Lake）图形性能提升；ISP4 摄像头驱动；AMD Zen 6 / Intel 相关硬件驱动改进。性能侧带来 AMD/Intel I/O 改进与更快的 poll 性能。最后一周有若干修复：回退到 DRM FIFO 调度（新「fair」默认引发回归）、声音设备 quirk、以及当日合入的 tlbi=ipi 启动选项。7.3 合并窗口随即开启，已有 40 个待合 pull request。
关注理由：7.2 是下一重大内核版本，直接决定 Ubuntu 26.10 等的图形/计算体验。对显示方向最重要的是 AMDGPU HDMI 2.1 FRL 初步落地（为 4K/高刷 HDMI 铺路）；计算方向则是缓存感知调度与 Arc B390 图形改善。同时需注意「fair」DRM 调度因 RX 9070 XT 回归被临时回退（见本期第 3 条），提示新版调度仍需打磨。

AMD 提交 109 补丁为 GFX 12.1 带来 RAS 支持（RDNA4 刷新 / 工作站或 DC 新品）
图形 计算
AMD 于周五晚放出 109 个补丁，为尚未公布的 GFX 12.1 图形引擎添加 RAS（可靠性 / 可用性 / 可服务性）支持。GFX 12.0 对应现有 RDNA4，GFX 12.5 对应 Instinct MI450，GFX 13 为 RDNA5；GFX 12.1 推测为某种 RDNA4 刷新方案，或为 Radeon AI PRO R9700 的继任 / 演进，甚至可能是 Instinct MI300A 的 APU 后继。补丁新增 SR-IOV 支持 等典型工作站 / 数据中心特性，而非消费卡功能。因提交时间过晚，Linux 7.3 已来不及合入，预计随 7.4（年内） 就绪。
关注理由：RAS 是数据中心 / 工作站 GPU 的关键可靠性能力，AMD 在开源驱动中持续补齐 GFX 12.x 的 RAS，说明 RDNA4 家族正向下游专业 / 计算场景扩展。对关注 AMD GPU 计算可靠性的用户，这意味着后续 Linux 上对 GFX 12.1 硬件的错误检测 / 恢复 / 遥测将更完善。

DRM 调度器「fair」策略回归修复补丁发布（RX 9070 XT 卡顿问题，或为 7.3 默认）
图形 内核
在 Linux 7.2 发布前，DRM 子系统因用户报告的回归被迫将新的「fair」调度策略默认回退到 FIFO。Igalia 工程师 Tvrtko Ursulin 跟进 RX 9070 XT 在 fair 策略下性能糟糕的问题（由 Luke Wildhardt 报告），用 两个不足百行补丁 修复了回归，目前认为已解决。Ursulin 表示修复后有望在后续内核把 fair 重新提升为默认，随后移除 FIFO 与 round-robin。fair 策略此前在 Steam Deck 上表现良好、对 GPU 客户端整体是赢面。
关注理由：这是上期（8/13）RX 9070 XT 桌面冻结回退事件的「正解」跟进。DRM fair 调度一旦稳定，可让多 GPU 客户端获得更公平、更低延迟的调度，对游戏 / 合成器体验有直接好处。本期修复为 7.3 重新启用 fair 默认铺路，值得持续跟踪。

D7VK 2.1 发布：老 Direct3D（D3D3/5/6/7）经 Vulkan 转译，加载更快、性能再优化
图形
D7VK 是在 Vulkan 之上开源实现 Direct3D 3/5/6/7 API 的项目（覆盖 DXVK 的 D3D8–11 与 VKD3D-Proton 的 D3D12 之前的老 API）。2.1 在近期一系列性能提升后，重点转向加载 / 启动速度：加速对象创建 / 销毁、缓存等，部分游戏加载时间较此前版本减半；并带来更多性能微调（如《生化危机 2》《地球帝国：征服的艺术》）。整体已相当稳健，适合在 Wine/Proton 下经 Vulkan 游玩老游戏。
关注理由：老游戏在 Linux 上的兼容层正持续成熟。D7VK 与 DXVK/VKD3D 互补，把更早的 D3D 版本也带入 Vulkan 高性能路径，对想在 Linux 上重玩经典老游戏的玩家是图形栈层面的实质利好。

Lemonade 11.6 集成 Muse-Glimmer 30B，实验性 TheNoise ROCm 图像生成
NPU 计算
AMD 主导的开源本地 AI 框架 Lemonade SDK 11.6 发布：将 Muse Glimmer 30B GGUF（Meta 本周发布的 30B 开源 agentic 模型，带 draft decoding、视觉、工具调用）接入 Llama.cpp 模型目录，支持开箱即用；新增实验性 TheNoise ROCm 图像生成后端，为 AMD Strix Halo / Strix Point 核显带来 Anima 与 Krea-2 支持；Llama.cpp ROCm 后端现支持多款老 Instinct（MI100/MI200/MI210/MI250 开箱即用）；另有 alias 子命令、可选视觉基准等改进。
关注理由：Lemonade 是 AMD 在「本地 AI（CPU/GPU/NPU）」方向的核心 SDK，11.6 同时补齐了大模型（30B agentic）与 ROCm 图像生成，并把老 Instinct 拉回开箱即用，利好想在锐龙 AI / Radeon 上跑本地多模态与图像生成的 Linux 用户，也体现 AMD ROCm 软件栈的可用性提升。

Marek Olšák 再发 19 补丁优化 RADV + ACO（像素着色吞吐、alpha-to-coverage）
图形
年初从 AMD 转投 Valve Linux 图形团队的传奇 Mesa Radeon 开发者 Marek Olšák，继续打磨 RADV Vulkan 驱动与 ACO 着色编译器。最新合入的 19 个补丁 聚焦提升某些条件下的像素着色器（PS）吞吐：当深度 / 模板片段着色输出无效果时可移除，极端情况下性能可能翻倍；另有深度 / 模板 / 采样掩码消除等改动。大补丁系列还修复了 GFX11/RDNA3 及更新的 alpha-to-coverage 性能（静态启用时），利好 DXVK 与 VKD3D。全部合入 Mesa 26.3（Q4 稳定）。
关注理由：RADV 是 Linux 上 AMD 显卡游戏 / 计算体验的核心开源驱动，ACO 是默认着色编译器。Marek 转投 Valve 后持续带来高频优化，直接提升 Radeon 在 Linux 上的游戏与 Vulkan 性能。本期聚焦像素着色与 alpha-to-coverage，对 DXVK/VKD3D 游戏有实际增益。

Intel「Jay」图形着色编译器通过 Xe2/Xe3 Vulkan CTS（Mesa 26.3）
图形
Alyssa Rosenzweig（原 Asahi Linux 图形、Valve 图形栈，现 Intel）主导的新 SSA 架构着色编译器 Jay，本周合入 Mesa 26.3-devel 的 63 个补丁，实现更多功能、VRT 优化与 bug 修复，现可在 Xe2 与最新 Xe3 硬件上通过 Vulkan CTS 一致性测试。Rosenzweig 表示此 MR 清掉了她手上最后一个「hack - do not upstream」补丁，上游在 Xe2/Xe3 上应基本通过 Vulkan CTS。Jay 将供 Mesa 的 Iris（OpenGL）与 ANV（Vulkan） 驱动使用，有望未来成为 Intel Linux 图形驱动的默认着色编译器。
关注理由：Jay 是 Intel 开源 Linux 图形栈的重要下一代基础设施，不到一年即从公开到通过 Xe2/Xe3 的 Vulkan CTS，进度显著。一旦成为默认着色编译器，将统一并现代化 Intel Arc 在 Linux 上的 OpenGL/Vulkan 路径，长期利好 Panther Lake 等新一代 Intel 显卡。

GNOME 51 Beta 发布：Mutter 支持背景模糊（Wayland）、SVG 光标、reduced-motion
显示
GNOME 51 Beta 现已可供测试，本轮以大量小幅改进为主：Mutter 合成器现支持 Wayland 下的背景模糊效果（ext-background-effect）；GNOME Shell 支持 reduced-motion 以减少动效、并加入与 KDE 同格式的 SVG 光标；GTK 支持 ext-background-effect 协议、重构 GDK frame-clock 提升精度并减少掉帧；控制中心的指纹管理 UI、Initial Setup 支持 systemd-homed、GVFS 空闲自动卸载、Nautilus 微调、Epiphany 重新启用 WebRTC、Glycin 支持 Radiance HDR 格式等。RC 约 8 月底，稳定版预计 9 月 18 日。
关注理由：背景模糊与 SVG 光标是 Wayland 桌面体验的「润色」关键项，Radiance HDR 支持也补全了 HDR 图片管线。GNOME 51 的这些变化对显示 / 桌面方向有实际意义，尤其磨砂玻璃类视觉效果与高刷下掉帧改善。

开源驱动为华硕 ROG Astral 显卡带来 12VHPWR 监控（6 路针脚电流/电压进 HWMON）
图形
开源开发者 Krzysiek Sokolowski 为 华硕 ROG Astral 显卡编写了树外 astral-hwmon 驱动，把 12VHPWR 连接器的 6 路独立针脚电流与电压 接入 Linux HWMON 子系统（测试硬件为带 ITE IT8915FN 监控 ASIC 的 ROG Astral RTX 5090 OC，同系列多型号应可用）。配合仓库内的 astral-guard 程序（规则源自 ASUS Power Detector+），可在电流失衡 / 电压异常时发出警告。驱动仅做监控、自身不做故障动作，但可与所有支持 HWMON 标准接口的用户态监控工具配合。
关注理由：12VHPWR 接口的过流 / 过热（乃至熔毁）风险长期是高端显卡的隐患，而 Linux 下此前几乎无法读取该传感器。astral-hwmon 让 ROG Astral 用户首次能在 Linux 上实时监测 12VHPWR 各针脚状态，配合 astral-guard 预警，是高端 N 卡在 Linux 上可用性与安全性的实质提升。
