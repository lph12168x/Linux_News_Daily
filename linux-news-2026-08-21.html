Intel Mesa 驱动将 Nova Lake S / U / H / HX 核显视为「稳定」
图形
Intel 在 Linux 上的开源 Mesa 驱动 —— Iris（Gallium3D / OpenGL）与 ANV（Vulkan）—— 不再把下一代 Nova Lake 处理器的核显当作实验性、默认关闭来处理。在今日合并的 Mesa 26.3-devel 代码中，Nova Lake 的 S / U / H / HX 全产品家族驱动代码均被认定为稳定并默认启用。此前 Linux 7.3 已决定把 Nova Lake Xe3P 图形视为稳定、移除 force_probe 强制探测要求，Mesa 用户态驱动随即跟进 —— 不再需要单独的 force probe 覆盖。该变更（commit bde9b9b）也会反向移植到当前的 Mesa 26.2 稳定系列。
关注理由：随着 Nova Lake 处理器在未来数月发布，开源 Linux 图形驱动已提前就位：开箱即用的稳定核显支持意味着 Panther Lake 后继平台的 Linux 桌面/游戏体验无需再手动加内核或 Mesa 参数。对关注 Intel 客户端图形在 Linux 7.3 + Mesa 26.3 上成熟度的开发者，这是一针强心剂。

Mesa 26.2.1 发布：首批稳定点版本带来数十项修复
图形
习惯等首个点版本再升级的用户有福了：Eric Engestrom 今日宣布 Mesa 26.2.1，作为 Mesa 26.2 的首个稳定点版本，带来一波健康的错误修复（各项均有、无特别重型的修复）。RADV（Vulkan）方面修复了 Vulkan Video（含 AV1）、ACO 编译器、gang submit 等；RadeonSI 同样有多项修正。Intel ANV 修复了光线追踪着色器 key 指针传递、并在命令缓冲末尾确保刷新 L1/L2 缓存。WSI 与 NIR 等公共区域，以及多个小驱动都修复了 buffer object 引用计数泄漏问题。同期还发布了 Mesa 26.1.8（上季度分支的最后一次点版本），官方建议用户迁移至 26.2。
关注理由：Mesa 26.2.1 是计划升级到 26.2 特性版的用户的稳妥入口：RADV 的 Vulkan Video/ACO 修复、ANV 的缓存一致性修复都直接关系到游戏与视频编解码稳定性，而 NIR/WSI 的引用计数泄漏修复则能消除长期运行合成器/游戏时的隐性内存增长。

X.Org Server 26.1 RC1：五年来首个特性版本
显示
紧接今日 XWayland 26.1 RC1 之后，X.Org Server 26.1 RC1 也已打 tag。这套 xorg-server 26.1 旨在成为五年来首个重大特性版本，接替 xorg-server 21.1 系列（尽管特性密度不如同期的 XWayland 26.1）。主要变化：移除 Autoconf/Automake、仅保留 Meson 构建系统；新增 DPMS 1.2 的 DPMSInfoNotify 事件；支持 XFixes 6.1 与 xorg.conf 的 AllowForceTerminate 选项；默认禁止字节交换（byte-swapped）客户端；默认关闭字体服务器连接；为 BSD 添加 DRM platform；Xorg 默认非 root 日志改至 $XDG_STATE_HOME/xorg；Xvfb 支持多 CRTC（至多 13 个鼠标按键）等。
关注理由：即便 Wayland 已成主流，X.Org Server 仍在维护并现代化：仅 Meson 的构建简化、默认拒绝字节交换客户端与字体服务器连接都属于安全加固，而 Xvfb 多 CRTC 等改动利好 CI/无头测试场景。对仍依赖 X11 会话或 Xvfb 的发行版与开发流程，这是一次务实的维护性跃升。

KMSCON 10.0.2：基于 KMS/DRM 的用户态终端迎来 asciicast 回放
显示
KMSCON 10.0.2 今日发布，是这款领先的用户态终端模拟器的最新更新。KMSCON 构建于 Linux 的 KMS/DRM 接口之上，是迄今在内核 VT 代码之外最可行的替代方案。它已被 KDE Linux、GNOME OS、即将到来的 Fedora 45 等用作内核 VT 的替代品。10.0.2 新增了终端会话的 asciicast 回放支持（asciinema 的 JSON 录制格式）；此外还有 blink 配置项、原子 DRM 模式设置失败时的恢复改进、8x16 字体改进、修正输入鼠标按键顺序，以及一系列其他 bug 修复。
关注理由：内核 VT（CONFIG_VT）正逐步被用户态方案取代，KMSCON 正是这条路线上的关键组件 —— 它直接关系到 Fedora 45 等发行版在纯 Wayland/GPU 显示路径下的控制台体验。原子 DRM 失败恢复改进让它在显卡热切换/模式设置异常时更健壮，asciicast 回放则为终端演示与故障复现提供了新能力。
