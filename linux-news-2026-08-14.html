GeForce NOW Linux 原生应用正式退出 Beta（NVIDIA 云游戏）
图形
今年初 NVIDIA 用 Flatpak 发布了 GeForce NOW 的 Linux 原生客户端，今日该原生 Linux 构建正式退出 Beta、达到生产级（production）状态。官方支持 Ubuntu 24.04 及更新版本，而得益于 Flatpak 打包，其他多数 Linux 发行版也能顺利运行。NVIDIA 同时为 GeForce NOW Linux 应用建立了 Flatpak 软件仓库，便于后续接收更新。此次转正发生在返校季之前，NVIDIA 工程师在 Beta 期间持续改进了性能与稳定性并对原生构建做了进一步打磨。
关注理由：GeForce NOW 是 NVIDIA 的云游戏方案，其 Linux 原生客户端达到生产级，意味着 Linux 玩家不必再依赖浏览器或 Windows 即可获得完整的云游戏体验；Flatpak 分发也让各发行版开箱即用。对「想在 Linux 上轻松玩 3A 大作」的用户，这是图形/游戏方向上的实质利好，也体现了厂商对 Linux 桌面前景的认可。

Linux 7.2 最佳新特性盘点：缓存感知调度、AMD Zen 6、AMDGPU HDMI 2.1 FRL
显示 内核 计算
Linux 7.2 内核预计于 8 月 16 日（本周日）发布，将被 Ubuntu 26.10 等发行版采用。Phoronix 盘点了其中最值得关注的特性，图形/显示/计算相关包括：缓存感知调度（Cache Aware Scheduling）——对拥有多末级缓存（LLC）域的现代系统可带来显著性能收益；AMD Zen 6 持续准备（随 EPYC 9006 "Venice" 推出，主流功能主线支持已就绪）；AMDGPU 初步 HDMI 2.1 FRL 支持（本版默认关闭，VRR/ALLM 仍未进）；合并 DC 电源模块 以更贴合 AMD Radeon 在 Linux 下的能耗行为；ISP4 驱动 合并（支持 HP ZBook Ultra G1a 等高端锐龙本的摄像头）；Intel 侧有坚固型 Panther Lake "R"、Diamond Rapids 与 Nova Lake H 的早期准备。此外 7.2 移除了 Hercules Monochrome ISA 等老旧显卡驱动。
关注理由：7.2 是下一重大内核版本，直接关系 Ubuntu 26.10 等发行版的图形/计算体验。对显示方向最有意义的是 AMDGPU HDMI 2.1 FRL 的初步落地（虽默认关闭，但为 4K/高刷 HDMI 铺路）；计算方向则是缓存感知调度与 Zen 6 支持。值得关注的是多个老显卡驱动被移除，提示用户旧硬件兼容性变化。

Intel XPU Manager 2.1 发布：Arc Pro 显卡监控新增 P2P 拓扑命令
图形 计算
Intel XPU Manager 2.1 现已发布，这是面向 Linux 与 Windows 的开源工具，用于监控与管理 Arc Pro 系列显卡——可通过 xpu-smi 命令查看设备利用率等指标。2.1 以修复为主，但新增了 xpu-smi topology --p2p 子命令，可打印 N×N 矩阵，显示每一对 GPU 是否支持 peer read / peer write / MDF fabric / atomics / PCIe 访问。同时提供了面向 Windows 与 Ubuntu Linux 的预编译二进制。
关注理由：对多卡 Arc Pro 计算场景，P2P 拓扑可见性直接决定能否做高效的 GPU 间直接数据传输（如推理/训练中的 NVLink 类通信）。xpu-smi 这类开源监控管理工具，补足了 Intel 在 Linux 上 Arc Pro 生态的可用性，是计算方向的实用更新。

AMD GAIA 0.23：可从终端安装/运行 AI 智能体
NPU 计算
AMD 的 GAIA 是构建在 Lemonade 之上的开源 AI 软件，可作邮件 AI 助手、Bash 编程智能体等。0.23 版新增直接从终端安装与运行 AI 智能体的能力：gaia hub list 列出可选智能体目录，gaia hub install 从命令行指定安装，并新增 gaia hub uninstall 卸载；另有 gaia skill 用于构建与分享 AI 技能。本版还要求所有 AI 智能体在行动前先询问用户，并关闭若干本地暴露面、做了多项安全加固。GAIA 0.23 基于开源 Lemonade SDK 11.5，已通过 GitHub 提供 Windows/Linux/macOS 版本。
关注理由：GAIA 是 AMD ROCm / Ryzen AI NPU 生态在「本地 AI 智能体」方向的一环，0.23 把智能体管理做到终端原生，降低了在 Linux 上部署/切换本地 AI 助手的门槛，并强调「行动前确认 + 默认更安全」。对想用锐龙 AI NPU 跑本地智能体的 Linux 用户，是工具链成熟度提升的信号。

Framework Laptop 13 Pro（Panther Lake）升级 Linux 7.1+/7.2 性能提升
图形 计算
新发布的 Framework Laptop 13 Pro 搭载 Intel Core Ultra Series 3 "Panther Lake"（Core Ultra X9 388H，集成 Arc B390 核显），在 Ubuntu 26.04 LTS 等现代发行版上运行良好。Phoronix 对比了 Ubuntu 26.04 在 Linux 7.0 / 7.1 / 7.2 三个内核系列下的表现：7.0 下一切可用，但升级到 7.1 稳定版、乃至即将发布的 7.2 内核，性能会进一步改善。作者指出这一内核升级带来的性能差异，大概率也会延续到其他 Panther Lake 笔记本。
关注理由：这再次印证「内核版本对 Panther Lake 图形/计算性能有实打实影响」——同一台笔记本，仅换内核即可见到提升。对准备买或可升级内核的 Panther Lake 用户有参考价值，也呼应了 7.2 内核（缓存感知调度、Intel 图形优化等）给实际体验带来的增益。
