Intel 为 DXVK 启用缓冲压缩（Buffer Compression），提升 Intel 显卡 DXVK 游戏性能
图形
Intel 开源 ANV Vulkan 驱动今日向 Mesa 26.3-devel 合入改动，为 DXVK（在 Vulkan 上转译 Direct3D 8/9/10/11 以运行 Valve Steam Play 游戏）启用缓冲压缩（buffer compression / CCS）。此前该选项仅对 VKD3D（Direct3D 12）开启、多数 DX12 游戏已受益，如今扩展到 DXVK。在 Intel Arc Battlemage 上《古墓丽影：暗影》提升 5.26%、《Total War: Warhammer 3》4.6%、《法老》2%；Xe3 Panther Lake 上《古墓丽影》提升 4.8%、Total War 系列约 2%。合并过程中维护者顺手删除了 anv_enable_buffer_comp 开关，改为对所有游戏/层默认开启以最大化收益。改动随 Mesa 26.3（预计 11 月稳定版）落地，现已可从 Mesa Git 获取。
关注理由：对 Intel 显卡 Linux 游戏玩家，DXVK 路径的缓冲压缩是免费的、普遍的帧率提升（多款游戏 2–5%）。这延续了 Intel ANV 驱动在 Mesa 中对 DXVK/VKD3D 游戏性能的持续打磨，也意味着 Battlemage 与即将到来的 Panther Lake Xe3 在 Linux 上的游戏体验进一步逼近 Windows。

COSMIC Epoch 1.6 发布（Rust 桌面：每应用音量控制 + 远程桌面准备）
显示
System76 主导的 Rust 桌面环境 COSMIC Epoch 1.6 于今日晚间发布。合成器新增对 Wayland wl-dmabuf-v6 协议的支持、现在从全屏 surface 获取 presentation feedback，并加入 EI（emulated input）协议支持——EI 是 COSMIC 远程桌面能力的基础，本期尚未提供远程桌面功能，但已为未来版本铺路。其他改进：COSMIC Edit 优化、COSMIC Greeter 新增 JPEG-XL 与 AVIF 图像格式支持、Greeter 可在运行时检测 logind 存在；并带来每应用音量/输出控制、COSMIC Terminal 分屏终端边框等。
关注理由：COSMIC 是 Linux 上少有的从零用 Rust 重写、原生 Wayland 的桌面环境。本期把 wl-dmabuf-v6、presentation feedback 与 EI 协议纳入，意味着合成器在显示协议完整度与远程桌面（屏幕共享/控制）方向上又进一步，对 Pop!_OS 及希望摆脱 X11/XWayland 的纯 Wayland 桌面用户有实际意义。

Modular 的 Mojo 语言在 Qualcomm 收购后全面开源（Apache 2.0·面向 CPU/GPU/NPU 计算）
计算
由 LLVM/Swift 之父 Chris Lattner 创立的 AI 公司 Modular，在近期被 Qualcomm 收购后，将其 Mojo 系统级编程语言以 Apache 2.0 许可全面开源（此前仅标准库开源；上周 Mojo 1.0 发布）。Mojo 1.0 定位为「AI 驱动世界」的生产级语言基础，设计面向从 CPU、GPU 到 AI 加速器（NPU）的多样硬件，受 Rust 等现代语言启发、可与 Python 互调，并可在 GPU 上编写内核。Modular 还计划将 Mojo 带到 Windows，补齐现有 macOS/Linux 支持。
关注理由：Mojo 主打「为 AI 硬件（CPU/GPU/NPU）而生」的系统级高性能语言，全面开源对 Linux 上的 AI 计算生态是利好：Qualcomm 作为 Linux/ARM 生态的重要玩家收购并开源 Mojo，意味着未来在 Linux 上用统一语言编写跨 CPU/GPU/NPU 的高性能 AI 计算内核有了更开放的路径，对关注 NPU/加速器计算的 Linux 开发者尤其值得跟踪。
