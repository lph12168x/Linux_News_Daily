开源 NVIDIA "Nova" Rust 驱动为 Linux 7.3 新增更多功能
GPU 内核
本周提交给 DRM-Next、瞄准即将到来的 Linux 7.3 合并窗口的，是一批 DRM Rust 核心与驱动改动。Rust 与 DRM 子系统的集成继续推进大量核心基础设施工作；当前两支最领先的 Rust DRM 驱动分别是 Nova（开源 NVIDIA GPU 支持，Nouveau 的继任者）与 Tyr（开发中、面向现代 Arm Mali）。在 Nova 一侧，本次带来：整合 GSP 启动流程、新增 vGPU 启动支持、TLV 固件镜像格式支持（便于 Rust 代码解析），以及针对 NVIDIA Hopper 与 Blackwell 支持代码的多项改进；Tyr 则获得固件加载与 MCU 启动改进。这些改动由 NVIDIA 工程师持续重金投入。
关注理由：Nova 是 NVIDIA 在 Linux 上摆脱闭源驱动依赖的关键开源项目，本次在 Blackwell/Hopper 支持、vGPU 启动与 TLV 固件等方向上的推进，意味着新一代 NVIDIA GPU 的开源内核栈正在逐步补齐能力。对希望用开源栈跑 NVIDIA 显卡（尤其数据中心/工作站 Blackwell）的用户，这是长期利好的基础建设进展。

Qt 工具集将引入 Edge AI 子模块（初期聚焦视觉 AI）
显示 计算
Qt Group 近期在 Qt 工具集里持续做 AI 集成（QML profiler 的 agentic 开发技能、Qt AI 编码助手、Qt Creator 中的 AI agent），最新的动作是准备在 Qt 工具集内新增 Qt Edge AI 子模块，让开发者以 runtime 无关的方式创建边缘 AI 应用；初期面向嵌入式设备，目标平台包括 NVIDIA Jetson/Thor、Qualcomm IQ、NXP i.MX95。初版聚焦 vision AI：提供 C++ API 构建「推理步骤 pipeline」来跑机器视觉任务（目标检测、分类），依赖 QtMultimedia 接收 QVideoFrames、并借私有 API 访问底层 GstBuffer 喂给推理 pipeline；初版由 Cursor AI agent 协作编写，后续补上 NXP NNStreamer 后端插件与人脸检测示例。
关注理由：Qt 作为主流跨平台图形/UI 框架，把边缘 AI 推理直接做成内建、runtime 无关的子模块，意味着嵌入式/边缘设备的「视觉 AI + UI」可以一站式开发——对工业检测、智能摄像头等跑在 Linux 上的图形栈是务实增强，也体现 AI 推理正下沉到传统 GUI 工具链。

Intel Xeon 678X（Granite Rapids WS）实测：Ubuntu 26.04 整体快约 9%
计算
HP Z4 G6i 工作站（搭载 Intel Xeon 678X / Granite Rapids WS，48 核 96 线程、4×32GB DDR5-6400、NVIDIA RTX PRO 6000 Blackwell 显卡）在 Windows 11 Pro（HP 出厂配置）与 Ubuntu 26.04 LTS（Linux 7.0 内核，干净安装）之间做了横评，共跑 100+ 项基准。结论：Ubuntu 26.04 LTS 整体比出厂的 Windows 11 Pro 快约 9%；在 Llama.cpp（Vulkan 后端）上两系统表现接近，部分模型/配置下 Windows 11 与 Ubuntu 旗鼓相当。后续还会有更多针对该 Xeon 6 的 Linux 专项基准。
关注理由：这是 Granite Rapids WS 工作站首份 Windows/Linux 正面对比，再次印证在高核数计算型负载上，Linux 的默认配置往往更具性价比——对选购/部署 Xeon 6 工作站的开发者与企业，是「开箱即用 Linux 即更快」的直观证据；同时也有利于验证 NVIDIA Blackwell 在 Linux 上的 AI 推理工况。
